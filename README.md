# Қазақтың біртуар ұлы Д.А. Қонаев: тарихи тұлға және дәуір шежіресі

10-сынып оқушысының ғылыми-зерттеу жобасы бойынша жасалған 3D виртуалды музей.

## Құрылымы
- **Орталық кеңістік:** портрет, бейнежоба, жоба туралы мәлімет
- **1-зал. Өмір жолы:** балалық шағы, отбасы, білім алуы, уақыт сызығы
- **2-зал. Инженер және ғалым:** тау-кен ісі, Ғылым академиясы, өндіріс картасы
- **3-зал. Қазақстанның дамуы:** өнеркәсіп, қалалар, «сол кезде · бүгін» салыстыру
- **4-зал. Тарих және қоғам:** мемлекеттік қызмет, 1986 жылғы желтоқсан, жетістіктер мен қайшылықтар
- **5-зал. Мұра және жады:** 3D кітаптар, QR-кодтар, қорытынды викторина
- **2-қабат:** конференц-зал, цифрлық кітапхана, VR-аймақ, шығармашылық аймақ

## Мүмкіндіктері
3D кеңістікте еркін жүру, экспонат туралы ақпарат, 3D кітаптар, интерактивті уақыт сызығы мен карта, үш тілдегі аудиогид (қазақ, орыс, ағылшын), әр залға арналған викторина, QR-кодтар, WebXR арқылы VR режимі.

## Іске қосу
`index.html` файлын браузерде ашыңыз (интернет қажет: Three.js пен қаріптер CDN-нен жүктеледі). GitHub Pages арқылы да жариялауға болады.

AI көмекші мен оқушылар жобаларының тақтасы толық түрде тек claude.ai нұсқасында жұмыс істейді; мұнда AI көмекші дайын сұрақтарға жауап береді.

## Дереккөздер
Фотосуреттер: Алматыдағы Д.А. Қонаев музейі (Төлебаев көшесі, 117). Портреттер галереясының суреті: RFE/RL. Мәтіндер ашық дереккөздер негізінде жазылған; толық тізім музейдегі «Дереккөздер» бөлімінде.
